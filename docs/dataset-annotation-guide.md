# 训练集版本与人工标注指南

系统支持在服务器授权目录中维护不可变的训练集版本，并对已有标签或新加入的无标签图片进行人工框选标注。

## 使用前准备

1. 在 `.env` 中配置服务器允许访问的数据根目录，例如：

   ```env
   TRAINING_DATASET_ROOTS=default=D:\free\datasets
   ```

2. 数据集目录采用 YOLO 检测格式：`images/train|val|test` 对应 `labels/train|val|test`。
3. 执行数据库迁移并启动服务。开发环境启动时会自动迁移；生产环境应先显式执行 Alembic 升级。

## 创建可编辑版本

进入“模型管理 → 训练集”：

1. 已发布的 `v1` 等版本是只读的，可直接用于训练。
2. 点击“创建编辑版本”，系统复制出独立目录和 `editing` 版本，不会修改正在训练或历史任务使用的数据。
3. 如果在服务器 `images/train`、`images/val` 或 `images/test` 中新增了图片，点击“重新扫描图片”。没有对应标签文件的图片会显示为“待标注”。

## 人工标注

点击编辑版本的“继续标注”：

1. 选择 `train`、`val` 或 `test`，并可筛选“待标注”“已标注”“已确认无目标”。
2. 选择类别，然后在图片上按住鼠标拖拽形成检测框。
3. 错误框可在右侧框列表中删除；完成后点击“保存标注”。
4. 确认图片确实没有任何目标时，点击“确认无目标”。这与“尚未检查”不同。
5. 需要新类别时输入类别名并点击“添加类别”。已有类别顺序不可随意改变，因为 YOLO 标签保存的是类别数字 ID。

推荐的安全帽复合标注为：

- `person`：完整人员框；
- `helmet`：佩戴安全帽的头部/安全帽框；
- `no_helmet`：未佩戴安全帽的头部框。

不要仅凭“检测到 person 且全图没有 helmet”自动生成 `no_helmet`，多人、遮挡和远景会导致错误关联。用于测评的 `test` 图片同样必须逐图确认；待标注图片不能发布。

## 校验与发布

1. 点击“校验”查看错误和警告数量。
2. 所有图片必须为“已标注”或“已确认无目标”，且标签、类别 ID、边界框与图片尺寸均有效。
3. 点击“发布”，系统重新校验、生成清单摘要并把版本原子切换为只读 `published`。
4. 新建训练任务时选择这个已发布版本。编辑中的版本不会出现在可训练列表中。

发布后若还需修改，请再次创建新的编辑版本；不要直接修改已发布目录中的文件。

## 常见问题

- 看不到新图片：确认图片在正确的 `images/<split>` 目录中，然后点击“重新扫描图片”。
- 无法发布：先处理全部“待标注”图片和校验错误；空场景必须明确点击“确认无目标”。
- 保存冲突：页面中的图片版本已过期，重新加载该图片后再编辑，避免覆盖另一位管理员的修改。
- 图片无法显示：检查文件是否仍在授权根目录内且内容未被外部程序替换；服务会校验路径和内容摘要。

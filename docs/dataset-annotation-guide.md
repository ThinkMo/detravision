# 训练集版本与人工标注指南

系统支持在服务器授权目录中维护不可变的训练集版本，并对已有标签或新加入的无标签图片进行人工框选标注。

## 使用前准备

1. 在 `.env` 中配置服务器允许访问的数据根目录，例如：

   ```env
   TRAINING_DATASET_ROOTS=default=D:\free\datasets
   ```

2. 数据集目录采用 YOLO 检测格式：`images/train|val|test` 对应 `labels/train|val|test`。
3. 执行数据库迁移并启动服务。开发环境启动时会自动迁移；生产环境应先显式执行 Alembic 升级。

## 创建可编辑版本

进入“模型管理 → 训练集”：

1. 已发布的 `v1` 等版本是只读的，可直接用于训练。
2. 点击“创建编辑版本”，系统复制出独立目录和 `editing` 版本，不会修改正在训练或历史任务使用的数据。
3. 如果在服务器 `images/train`、`images/val` 或 `images/test` 中新增了图片，点击“重新扫描图片”。没有对应标签文件的图片会显示为“待标注”。

## 人工标注

点击编辑版本的“继续标注”：

1. 选择 `train`、`val` 或 `test`，并可筛选“待标注”“已标注”“已确认无目标”。
2. 选择类别，然后在图片上按住鼠标拖拽形成检测框。
3. 不同类别使用不同颜色：`person` 为蓝色、`helmet` 为绿色、`no_helmet` 为红色；其他自定义类别使用稳定的备用颜色。
4. 错误框可在框列表中删除，也可以点击“撤销”或按 `Ctrl+Z`（macOS 为 `Command+Z`）撤回最近一次框选/删除。
5. 完成后点击“保存标注”。保存成功会自动前进到当前列表的下一张图片，不会跳回第一张；“确认无目标”成功后也会自动前进。
6. 确认图片确实没有任何目标时，点击“确认无目标”。这与“尚未检查”不同。
7. 需要新类别时输入类别名并点击“添加类别”。已有类别顺序不可随意改变，因为 YOLO 标签保存的是类别数字 ID。

推荐的安全帽复合标注为：

- `person`：完整人员框；
- `helmet`：本次新增版本统一为佩戴安全帽的完整可见头部框（包含安全帽），不与帽壳框混用；
- `no_helmet`：未佩戴安全帽的完整可见头部框。新旧框口径不同必须分版本修订；具体规则见 [施工监控安全帽佩戴状态标注规范](helmet-wearing-annotation-standard.md)。

不要仅凭“检测到 person 且全图没有 helmet”自动生成 `no_helmet`，多人、遮挡和远景会导致错误关联。用于测评的 `test` 图片同样必须逐图确认；待标注图片不能发布。

## 校验与发布

1. 点击“校验”查看错误和警告数量。
2. 所有图片必须为“已标注”或“已确认无目标”，且标签、类别 ID、边界框与图片尺寸均有效。
3. 点击“发布”，系统重新校验、生成清单摘要并把版本原子切换为只读 `published`。
4. 新建训练任务时选择这个已发布版本。编辑中的版本不会出现在可训练列表中。

发布后若还需修改，请再次创建新的编辑版本；不要直接修改已发布目录中的文件。

## 常见问题

- 看不到新图片：确认图片在正确的 `images/<split>` 目录中，然后点击“重新扫描图片”。
- 无法发布：先处理全部“待标注”图片和校验错误；空场景必须明确点击“确认无目标”。
- 保存冲突：页面中的图片版本已过期，重新加载该图片后再编辑，避免覆盖另一位管理员的修改。
- 图片无法显示：检查文件是否仍在授权根目录内且内容未被外部程序替换；服务会校验路径和内容摘要。
- 保存后没有切到下一张：当前筛选结果中已经没有下一项；切换状态筛选或数据分区继续处理。

## 图片与标注的坐标一致性

图片、已有框和新建框统一使用原图宽高建立坐标系。界面等比显示图片，鼠标坐标转换会扣除上下或左右留白；拖出图片边界时，预览框与保存框使用同一裁剪范围。切换图片后会清除未完成的拖动。

保存的 YOLO 坐标始终相对于原图归一化，重新加载后再按原图尺寸还原。已用横图、竖图与 2560×1440 图片验证保存和重载的像素位置一致性；这些测试验证坐标转换，不代表公开来源标签的语义和边界已经人工确认。若原有标签与目标错位，应保留来源与修订记录，逐图确认，不能统一套用未经核实的平移或缩放。

从侧栏进入“模型管理”默认展示“训练集”。显式的训练任务或模型版本链接仍打开对应 Tab。
## 分区、分页与待核验数量

图片列表每页 50 张，下方显示当前分区（或筛选结果）总数、显示范围和页码，可点击“上一页”“下一页”。当前页全部已标注不代表整个版本完成；请分别检查训练集、验证集和测试集，可用状态筛选查找待标注图片。

保存本页最后一张后，若筛选仍包含该图片且存在下一页，会继续下一页；待标注筛选下，保存后该图片离开结果，页面按刷新后的结果继续，避免跳过图片。

发布检查整个版本的所有分区。失败弹窗分别显示待核验张数、其他错误和警告，并给出各分区待核验数量；“继续核验”可返回标注页。已有框但尚未人工确认的图片仍需保存标注；无目标图片需明确确认无目标。
## 全部标注完成后的发布提示

每次保存标注或确认无目标成功后，系统查询训练集、验证集、测试集三个分区的最新待标注总数，包括重新保存已经核验的图片。也可点击“检查完成状态”，无需重复保存。只有整个版本均为零，才提示“全部标注已完成，是否发布？”。当前分区完成、其他分区仍有待标注图片时，会提示当前分区已完成，列出各分区剩余数量，并提供前往下一待标注分区的按钮。检查后的分区数量也会保留在页面上。

点击“校验并发布”后，系统读取最新版本号并执行既有发布校验；校验错误会展示明细，用户可继续核验。点击“取消”保留编辑版本。完成状态查询失败时，标注保存仍然有效，可以点击“重新检查完成状态”重试。
## 删除不需要的图片

编辑中的版本支持“删除当前图片”，也可勾选图片列表中的项目，再点击“删除所选”；“全选本页”仅选择当前页，切换分区、筛选或页码会清除勾选。确认弹窗会列出文件名和数量，取消不会修改图片。当前图片有未保存标注时会提示一并放弃。

确认删除后，所选图片及其标注退出当前集合，图片数量和分页随即更新；删除末页最后一张后会回到有效页。已发布版本只供查看，不能删除。删除失败或版本过期时保留图片并显示错误；重新加载后再操作。

服务器将移出的文件及来源记录暂存在该集合的 .removed-images 目录，重新扫描不会将它们加入图片列表。源素材和其他集合中的副本不受影响。界面目前提供移除操作，回收目录的文件保留作人工恢复依据。需要保留的无人背景仍可用“确认无目标”，继续作为背景训练样本。

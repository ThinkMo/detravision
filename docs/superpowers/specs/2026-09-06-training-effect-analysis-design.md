# 训练效果分析设计

## 目标

在通用目标检测训练完成后，为每个类别提供可操作的置信度建议、最佳 F1、误检数和漏检数，并展示 Ultralytics 生成的 PR、F1、Precision、Recall 曲线。

## 设计

- 评估仍使用独立 `test` split，训练行为与权重产出不变。
- 从评估对象的 F1-Confidence 曲线计算每类别 F1 峰值及对应置信度。
- 从混淆矩阵计算每类别误检和漏检；结果写入运行目录的受控 `analysis.json`。
- 复制评估目录中的标准曲线到运行目录，并通过固定白名单 API 内联提供。
- 训练详情按类别展示建议值和错误计数；缺少曲线或旧任务不报错，仅隐藏对应内容。
- API 不暴露数据集路径、运行目录或任意文件读取能力。

## 验收

- 分析算法覆盖合法、缺失和畸形指标。
- 新任务可查看分析 JSON 和四类曲线，旧任务保持兼容。
- 后端、前端单元测试和构建通过。

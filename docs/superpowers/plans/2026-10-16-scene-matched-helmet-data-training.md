# 客户施工监控场景数据与训练执行计划

> **For agentic workers:** Use superpowers:executing-plans to execute inline. This is a data experiment in an isolated local data directory; no product feature work, commits, account messages or deployment are required.

**Goal:** 以客户 7+34 张照片共同定义场景，寻找高质量、匹配监控视角与佩戴关系的训练素材并开展实测；优先有 2020 年后实拍证据，不要求来源预先标注。

**Architecture:** 来源核查、原图抽样、场景与重复分组、标签制作与视觉复核、训练和分组评估顺序执行。原始来源、日期证据、候选标签与审核标签分层保存；不覆盖任何客户原图、现有版本或人工标注。

**Tech Stack:** Python 3.12、requests、Pillow、NumPy、Ultralytics、现有训练 CLI；GTX 1060 6GB。

**Spec:** 用户本轮指令、data/customer-targets-20261016/assessment.md、data/dataset-audit-20261015/domain-gap-20261016.json。

## Global Constraints

- 高质量与业务匹配优先于数量和现成标签；2020 年后为优先项，采集年、发布日期、文件日期分开记录。
- 客户两批图片共 41 个文件作为统一业务参照，检查场景亲缘，禁止训练原图或其衍生物混入评估。
- 每个可训练图片需完整头部佩戴状态；模糊或不确定目标不能强行赋值、不能以未检出作未戴帽真值。
- 数据许可独立于代码许可。未核实的数据不宣称可用于客户业务训练；无标注可先收集，但在标签通过前不混入有监督训练。
- 不修改线上模型，不覆盖现有人工标注，不发出邮件，不采购，不使用私有客户图片作外部检索或上传。
- 下载与实验产物放 data/scene-matched-helmet-20261016；最终新增集独立版本化，试验模型不自动激活。

## Review Focus

- 2024/2025 发布但复用旧照片的来源：日期字段标 unknown，不能写实拍年已确认。
- 只有人员框：保留为人员框，另制头部标签，不能错误映射。
- 同视频相邻帧：先分组再分区，不能以图片随机划分掩盖泄漏。
- 高清但头部已模糊或打码：按目标区域检查，不能只看文件尺寸。
- 帽子手持或放在地面：不得当戴帽头部；普通帽、黑色安全帽和遮挡需逐图复核。

- [ ] 仅保留有可追溯许可、监控域相符、可判断目标的来源候选；为缺标注素材生成独立候选，记录教师及置信度。

- [ ] 场景和视频分组、跨源去重，分离训练/验证/测试；写 data.yaml、manifest、来源说明、verification。
- [ ] 验证内容摘要、图像与标签对应、非法坐标/类别、分区来源交叉、客户图及衍生物隔离。先验证失败检查能检出构造的违规输入，再运行全量验收。

## Task 3: 训练与客户场景评估

- [ ] 确认可训练集有可靠标签且无活跃训练；以原始预训练权重开始独立实验，固定分组、seed、配置和模型摘要。
- [ ] 在 GTX 1060 6GB 上先验证合理 batch 与输入尺寸，训练保留 best/last、有效配置、训练曲线和逐类指标。
- [ ] 公开隔离评估与客户 41 张案例评估分开；客户疑难例保留不确定状态，不强行凑真值或承诺 90%。
- [ ] 如质量、授权或标签不足，完成其余可做工作，明确记录具体缺口；不拿旧数据重训冒充本目标已完成。
